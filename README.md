# 多终端课堂学习平台

一个简洁的前端示例网站，支持：

- 用户注册/登录（学生、老师双角色）
- 学生查看课前预习资料、课上 PPT、课后作业
- 老师上传各类型教学内容
- 自适应布局，适合电脑、平板、手机等多终端访问

## 使用方式

1. 直接双击 `index.html` 打开，或使用本地静态服务器启动。
2. 先注册账号：可选择老师或学生身份。
3. 老师登录后可上传资料；学生登录后可查看全部资料。

## 本地开发

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。

## 数据说明

示例使用 `localStorage` 保存用户、会话和学习资料（仅用于演示）。
